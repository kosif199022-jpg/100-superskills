# 51 · صفحة الهبوط الفاخرة — Premium Landing Page

صفحة هبوط من ملف HTML واحد بمستوى الجوائز: استبيان إجباري من 4 أسئلة (المنتج والوعد، والجمهور، والهوية، والنبرة)، ثم نسخة إقناعية، وتصميم بحركة GSAP وعمق بارالاكس، وتوافق جوال وRTL، وSEO وأداء، وتصوير للتحقق.

## متى تُستخدم

- بالعربية: صفحة هبوط، لاندنج، موقع لمنتج، صفحة بيع، صفحة تعريفية.
- بالإنجليزية: landing page, sales page, one-pager, product page, promo page.

## خط الإنتاج (بالترتيب)

1. الاستبيان: المنتج ووعده في جملتين، والجمهور (تقني، أعمال، مستهلك)، وألوان الهوية أو الافتراضي، والنبرة.
2. النسخة: عنوان 8-12 كلمة بالفائدة، وسطر فرعي، و3-6 ميزات بالنتيجة لا بالخاصية، ونداء واحد مكرر.
3. البنية: بطل، ومشكلة، وكيف يعمل، وإثبات اجتماعي، وأسعار إن وُجدت، وأسئلة شائعة، ونداء ختامي.
4. التصميم: HTML واحد بـ CSS وJS مضمّنين، وخطوط Google وGSAP من CDN فقط، ومتغيرات CSS للألوان، وحركة تحترم reduced-motion.
5. التحقق: تصوير بثلاثة أحجام، وفحص التباين وLighthouse، وSEO (العنوان والوصف وOG وJSON-LD).

## بوابات الجودة (لا تسليم قبل المرور)

- لا نص مكرر عام («حلول مبتكرة»).
- يعمل على 375px بلا تمرير أفقي.
- تباين AA وLCP أقل من 2.5 ثانية.

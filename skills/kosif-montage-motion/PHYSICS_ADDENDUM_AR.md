# KOSIF Structural Twin — تحديث مستوحى من المرفق (8 أكتوبر 2026)

## ما الذي نُفّذ؟
منظومة مساندة لأداة KOSIF Montage & Motion وKOSIF SEE تقدم خطّ العمل SHAPE / JOINT / LOAD / BREAK / SWAP / RANK.

### التنفيذ القابل للتشغيل
- تحليل رياضي فعلي **لشبكات قضبان ثنائية الأبعاد مفصلية الاتصال** (pin-jointed trusses) بافتراض مرونة خطية وإزاحات صغيرة.
- حساب القوى الداخلية والإجهاد والمحاور المتحركة وردود الأفعال على المساند.
- ترتيب قضبان النموذج حسب مضاعف الحمل اللازم للوصول إلى حد إجهاد المادة، وتسجيل الفشل الافتراضي على شكل إزالة قضيب تلو الآخر.
- التبديل التجريبي للقطعة بمواصفات جديدة وإعادة حل النموذج بالكامل.
- لوحة HTML مستقلة، لا تستخدم مكتبات CDN ولا إنترنت، وتدعم الهاتف والكمبيوتر.
- إدراج الفكرة في توجيه خطط الفيديو الستية باستخدام الأداة `proplan`.

### المصدر والحدود
- الصورة والفيديو المرفقان **مرجعان بصريان وفكرة عامة** وليس بيانات هندسية. الادعاء المنشور عن Anthropic غير مُعتمد هنا كحقيقة مؤكدة.
- المثال المرفق نموذج مثلثي اصطناعي بقيم مختارة للتجربة، وليس إعادة بناء الشخصية من الفيديو.
- المحرك **ليس** حلاً عاماً لأي جسم ثلاثي الأبعاد، ولا يحسب الانبعاج أو الليونة أو التعب أو التصادم أو الاحتكاك أو الأجسام الصلبة أو ديناميكيات السرعة.
- لا يجوز الاعتماد عليه لإقرار سلامة مبانٍ أو منتجات أو معدات فعلية.
- الأداة المحلية لا تقدم إثباتًا مستقلًا على تشغيل نظام **Full Pro**؛ مصفوفة الأوامر تعيده بالحالة `NOT_FULL_PRO` إذا لم تتوفر إيصالات حقيقية مستقلة.
- لم تُنشر التعديلات في KOSIF SEE المتصل، ولم تُحدث مستودع GitHub أو Cloudflare. الحزم ملفات قابلة للفحص والدمج.

### القياس التجريبي
النموذج A-B-C بثلاثة قضبان، تحت حمل رأسي 12000 نيوتن على B. أول حد إجهاد مُقدر عند مضاعف حمل حوالي **2.9463×** من الحمل الأساسي. عند مضاعفة مساحة AB، أصبح القضيب BC هو الأكثر تقييدًا، بينما بقي أول حد إجهاد تقريبًا دون تغير. عند تحميل 3.2× يصل النموذج إلى حد إجهاد AB وBC، ويعتبر سيناريو الإزالة المثالي أن حذف AB يجعل النموذج غير مستقر.

### اختبارات منفذة
- 6 اختبارات الحزمة السابقة ظلت ناجحة.
- أضيف 12 اختبارًا للوحدات، الإجمالي **18/18 ناجحًا**.
- اختباران للمتصفح على **1365px و390px** بدون أخطاء JavaScript، وتم تغيير SWAP والحمل.
- فحص توازن القوى مع نواتج تحليليّة يدوية، حماية من الأرقام غير المنتهية والوصلات غير المستقرة، تحديد صلاحيات إدخال SWAP.

### أمثلة الاستخدام
```bash
cd kosif-montage-motion
python scripts/kmotion.py structural --sample --swap AB --area 0.0002 --fracture-scale 3.2 --out out/twin.json
python scripts/kmotion.py twinview out/twin.json --out out/twin.html
python scripts/kmotion.py proplan --task 'مجسم هيكل: اختبر الوصلات والأحمال والانهيار وتبديل جزء' --seconds 18 --out out/storyboard.json
python -m unittest discover -s tests -v
```

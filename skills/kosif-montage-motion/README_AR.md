# KOSIF Montage & Motion v5.2 — استوديو المونتاج والموشن

هذه نسخة تعمل محلياً من أداة المونتاج والموشن المرفقة، وتضيف التخطيط الاحترافي والتحقق من المصادر دون الادعاء بتنفيذ Full Pro أو تحميل 15 ألف مهارة دفعة واحدة.

## البدء السريع

```bash
python scripts/env_check.py
python scripts/kmotion.py help
python scripts/kmotion.py proplan --task 'موشن جرافيك سينمائي مدته 12 ثانية باللهجة المصرية' --seconds 12 --fps 30 --aspect 9:16 --out plan.json
python -m unittest discover -s tests -v
```

### عمل ريلز مع تفريغ زمني جاهز
```bash
python scripts/kmotion.py reel source.mp4 --out final.mp4 --transcript source.words.json --no-decaption --credit '@original_author'
```

إذا كان التفريغ الصوتي غير مثبت، يمكنك استخدام ملف كلمات مضبوطة التوقيت بصيغة `.words.json`. لا يتولى البرنامج إنشاء توقيت زائف من النص.

## جديد v5.2
- **`audio2motion` (Voice2Motion):** ارفع تعليقاً صوتياً + نصه (أو ملف cues.json) → فيديو موشن جرافيك تختار مشاهده حسب **معنى** كل جملة وتتنفس مع طاقة الصوت الحقيقية. الخطوط تُكتشف تلقائياً على ويندوز، والعربية مشكّلة بشكل صحيح.
  ```bash
  python scripts/kmotion.py audio2motion voice.wav --transcript voice.txt --out out/voice.mp4 --size 1080x1920 --fps 30
  ```
- **`bridge`:** عميل اختياري لمخطط Workbench الخاص (خطة/تحقق/تجميع) — يحتاج `KOSIF_SITE_TOKEN` و`--allow-remote`، ولا يصيّر شيئاً.
- تصحيحات من تدقيق v5.1: أسماء المشاريع محصورة داخل `projects/`، العناوين مهرّبة في HTML، `Encoder` يرفع خطأ إذا فشل FFmpeg.
- فيديو 5 ثوانٍ من البداية للنهاية: راجع §12 في SKILL.md.
- تشغيل بنقرة (نمط KOSIF-Motion.zip): `python scripts/kmotion.py` بلا وسائط يعرض قائمة عربية مرقّمة.

## إضافات التطوير
- مخطط 5 مشاهد متصلة زمنياً بالمعدل FPS.
- تدقيق المدخلات وحالة الاعتماد قبل المونتاج.
- كتابة مصدر الفيديو على الشاشة دون الاعتماد على خط Windows.
- فحص قدرة البيئة على إنتاج الريلز عند توفير توقيت كلمات حتى بدون نموذج Whisper.
- بوابة Full Pro آمنة: خطة محلية ≠ تنفيذ Pro حقيقي؛ الطلب المحمي ينهي بخروج 3 إذا لم تتوفر أدلة معتمدة.
- توجيه استخدام مهارات KOSIF Atlas بعينة مناسبة ومحدودة؛ لا تحميل جماعي غير آمن.

الملف `UPGRADE_REPORT.md` يوثق التغييرات وحدود التحقق. و`references/KOSIF_SEE_INTEGRATION.md` يوثق خطوات وصل الإضافة بـ KOSIF SEE بدون إنشاء أداة منافسة.

## إضافة جديدة: KOSIF Structural Twin
المنصة تدعم الآن نموذجاً تعليمياً من ست مراحل (SHAPE / JOINT / LOAD / BREAK / SWAP / RANK)
للهياكل المفصلية المستوية، مع حل عددي للقوى والإجهادات، وترتيب نقاط الضعف، وإعادة الحساب
بعد تغيير قطعة، وواجهة HTML تفاعلية لا تحتاج للإنترنت.
**الحدود:** ليست محاكاة هندسية ثلاثية الأبعاد معتمدة؛ ولا يمكن استنتاج خواص المواد من صورة.
اطلع على `references/STRUCTURAL_TWIN.md` وقم بتشغيل اختبارات الحزمة قبل استخدامها.

## الإصدار 1.3 — أسرع، وأشكال ثلاثية الأبعاد، وتوأم هيكلي ثلاثي الأبعاد
- **أسرع:** التصيير يقسّم الفيلم إلى أجزاء متتالية تُصيَّر في عدة صفحات متصفح بالتوازي، وكل جزء يُرمَّز وحده ثم تُدمج الأجزاء بلا إعادة ترميز. الالتقاط يمر عبر CDP بوضع `optimizeForSpeed` مباشرة إلى FFmpeg.
  ```bash
  python scripts/kmotion.py render projects/bunny_twin --engine studio --workers 4 --blur 2
  ```
- **أشكال 3D:** عدّة جديدة `scripts/kit/shape-kit.js` (`window.K3S`) لنحت المجسمات من دوال المسافة (SDF): كرات، إهليلجات، مخاريط مستديرة، صناديق، حلقات، مع دمج ناعم وحفر وتلوين، ثم شبكة مغلقة بأسطح ناعمة. فيها خامة القطيفة (plush)، عيون لامعة، وأرنب كيوت جاهز بهيكل حركة (رأس، أذنان، ذيل).
  دليل الاستخدام و«وصفة الشكل الكيوت»: `references/shape-kit.md`.
- **توأم هيكلي 3D:** `structural_twin.py` يحل الآن الجمالونات الفراغية (x/y/z) إضافة إلى المستوية.
- **إصلاحات:** اكتشاف متصفح Playwright في بيئات السحابة، معايرة الصوت على مرحلتين (−14 LUFS للمقاطع القصيرة)، وتشغيل esbuild على لينكس.
- **مثال:** `scripts/projects/bunny_twin` — فيديو 5 ثوانٍ 1080×1920 لأرنب كيوت يمر بمراحل SHAPE → JOINT → LOAD → BREAK → SWAP → RANK بأرقام محسوبة فعلاً (قيم توضيحية مختارة، ليست قياساً للعبة حقيقية).

## الإصدار 5 — أداة واحدة من كل الفروع
- **دمج:** فرع v4 (تصيير متوازي سريع، مسودات، أدوات يومية: قص الصمت، تحويل النسبة، التصدير، الغلاف…، وعدّة المعمل)
  مع فرع Pro 1.3 (عدّة الأشكال ثلاثية الأبعاد، التوأم الهيكلي ثلاثي الأبعاد، معايرة الصوت على مرحلتين) في محرك واحد.
- **`direct` — مونتاج موجَّه تلقائي لمقطع متكلم:** الكاميرا على المتحدث، كلمة مفتاحية لكل جملة (لا تغطي الفم أبداً)،
  رقم ← حلقة ساعة، القطع ← كلمة انتقال، والذروة حسب البلاغة (أول جملة كاملة بعد آخر تكرار للازمة).
  ```bash
  python scripts/kmotion.py direct clip.mp4 --name my_edit --credit "insta: handle"
  python scripts/kmotion.py render projects/my_edit --engine studio
  ```
- **`verse` — فيلم نص حركي من صوت فقط:** أغنية أو قصيدة أو دعاء أو تعليق صوتي ← سطور مقسّمة على مواضع الوقف الطبيعية،
  كلمة مفتاحية حين تستحق، ذروة عند آخر رجوع للازمة، وخلفية ضوئية تتنفس مع الإيقاع (أو صور بقطع وزووم بطيء
  والنص بعيد عن الوجوه). النص الصحيح (`--text`) يُركَّب على توقيت الكلام حتى مع التشكيل والهمزات.
  ```bash
  python scripts/kmotion.py verse song.mp3 --name my_song --text lyrics.txt --title "العنوان" --mood night
  python scripts/kmotion.py render projects/my_song --engine studio
  ```
  لا تُضاف موسيقى افتراضياً (الأغنية لها موسيقاها، والدعاء والتلاوة يبقيان بلا موسيقى)؛ `--music auto` يضيف خلفية
  موسيقية فقط لتعليق صوتي بلا موسيقى.

## v6.0 — موقع الاستوديو المحلي (KOSIF Motion Web)

```
python scripts\kmotion.py web          أو انقر «KOSIF Motion Web.bat»  →  http://127.0.0.1:8766/
```
الموقع هو اليد، وClaude هو العقل: ارفع الوسائط، شغّل أي وصفة من نموذج، عاين المشاريع وعدّلها وصيّرها، اكتب تايملاين
JSON وشاهد شريطه، تابع المهام بسجل حي، واستعمل Workbench (خطة → تحقق → manifest → معاينة → MP4 محلي). تبويب Claude
يرسل الطلب عبر MCP أو CLI أو بالنسخ واللصق، ولا يُنفَّذ شيء قبل «تطبيق». التفاصيل في `references/web-studio.md`،
والتايملاين في `references/timeline-schema.md`، ومصادر v6 في `references/atlas-v6-sources.md`.

## v6.1 — محرر Studio في المتصفح وتصدير MP4 دقيق

- محرر المونتاج من حزمة Workbench v4 صار جزءًا من الموقع المحلي على `/studio/`، ومنشورًا في السحابة باسم KOSIF Studio Cloud.
- زر «تصدير MP4 دقيق» يرسم كل إطار بنفسه ويرمّزه بـ WebCodecs مع صوت AAC مطبّع على −14 LUFS؛ لا يحتاج زمنًا حقيقيًا ولا تبويبًا ظاهرًا ولا يُسقط إطارات.
- `kmotion studio-import` يحوّل مشروع Studio إلى تايملاين يُصيَّر بجودة كاملة عبر FFmpeg.
- مشهد MIDNIGHT من حزمة v4 صار مشروعًا في المحرك: `python scripts\kmotion.py render projects/midnight_cat`.

## v6.2 — صفحة المراجعة وبرومبتات الفيديو
- `kmotion review init مشروع|تايملاين|فيديو` ثم افتح `http://127.0.0.1:8766/review/الاسم/`: عدّل النصوص والألوان والتوقيت، ثبّت ملاحظة (N)، اعتمد المشاهد، ثم «أرسل إلى Claude». تُحفظ الملاحظات ليقرأها Claude (`kmotion review feedback`) ويطبّق المرتبط منها حرفياً (`kmotion review apply`). الصفحة مشغّل Motion OS من Jason Lee (رخصة MIT).
- `kmotion aiprompts`: برومبتات لكل لقطة بالطبقات السبع لـ Veo وSora وKling وRunway.
- `install.bat` للتثبيت بنقرة، و`KOSIF Motion.bat` للقائمة العربية.
- مثال: `projects/night_boat` — مركب في البحر ليلاً، 5 ثوانٍ.
- فيديو إطلاق لأي مشروع أو موقع (طريقة /brag): `kmotion brag init مجلد|رابط` ثم `kmotion brag deliver`.
- `kmotion poster فيلم --bake`: أقوى إطار مستقر يصبح الإطار الأول، فتظهر صورة الغلاف في كل منصة.
- `kmotion readable`: هل يبقى كل سطر وقتاً يكفي لقراءته؟ و`kmotion sfx`: 20 مؤثراً صوتياً حراً (CC0) للتايملاين.
- استُعيدت من v5.1: رموز بالمعنى وعدّاد للأرقام في verse، وعناوين audio2motion من كلام المقطع نفسه.
- تحليل فيديو مرجعي: `kmotion analyze فيديو` يقيس الفيلم كله لقطة بلقطة ويستخرج إطارات، ثم `kmotion omniprompt` يكتب برومبت Google Omni Flash جاهزاً بتعديلاتك (الاسم، الألوان، النص، المدة، المقاس).
- `kmotion final مشروع`: التصيير النهائي بأعلى جودة (1080 على الأقل، بلا فقد، غلاف وفحص)، والمسودات (`preview`) لجولات المراجعة.
- `kmotion fetch رابط`: تحميل فيديوهات وصور من Pinterest (دبوس أو لوحة كاملة) وتيك توك وإنستغرام وفيسبوك ويوتيوب إلى مكتبة الوسائط، مع نسخة جاهزة للمونتاج وسجل بمصدر كل ملف وصاحبه.
- `kmotion audiolab ملف --mode voice`: عزل الصوت البشري، أو الموسيقى فقط، أو فيديو بلا موسيقى/بلا صوت (من Cinema C).

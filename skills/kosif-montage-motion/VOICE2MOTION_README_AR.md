# KOSIF Voice2Motion — إضافة موشن جرافيك بالصوت والسيناريو (v2.1)

المحتوى متوافق مع مسارات `verse` و`direct` الحالية. الأمر الجديد **audio2motion** يستخدم صوت المستخدم، واختيارات مرئية لكل عبارة (طقس، مرور، دعم، استرداد، عام) وتحريكًا يعتمد على مستوى الصوت لإنتاج MP4.

## من سطر الأوامر

```bash
python scripts/kmotion.py audio2motion /path/to/speech.wav --cues /path/to/cues.json --out /path/to/video.mp4 --fps 24 --size 540x960
```

أو عبر بايثون مباشرة:

```bash
python scripts/audio2motion.py speech.wav --transcript transcript.txt --plan-only
python scripts/audio2motion.py speech.wav --cues speech.cues.json --out speech-motion.mp4
```

- **ليست تفريغًا صوتيًا آليًا:** تحتاج النص أو ملف توقيت كلمات من مصدر مستقل. إذا زودت النص فقط، التوقيت تقديري بحسب طول العبارة، وليس محاذاة قسرية محسوبة.
- يمكن إنشاء `cues.json` من أحداث الكلام المسموعة، فتتبع المشاهد المعنى ومواضع التوقف.
- يحافظ على الصوت الأصلي دون إضافة موسيقى افتراضية.
- يعتمد على Python + NumPy + Pillow + FFmpeg؛ لا مفاتيح API ولا اتصالات مدفوعة.
- المشاهد دلالية ومصممة متجهياً 2D؛ ليست توليد فيديو فوتوريالي من وصف تلقائي.
- يتغير المشهد والحركات؛ ويمكن فتح JSON الناتج وتعديل النصوص والتوقيت ثم إعادة الإخراج.
- يعتمد في الخط الإنجليزي على خطوط النظام المحلية؛ لم تُرفق أي ملفات خطوط مع الأرشيف.

## التطوير المستقبلي
- ربط ASR اختياري ذي timestamps بالكلمات، مع تدقيق بشري.
- إضافة مكتبة مخططات مرئية واسعة وملفات حركة أصلية لكل مفهوم.
- تصدير عدة نسب أبعاد مع فحص bounds وكثافة النص، وإضافة ترجمة متعددة اللغات.

التفعيل هنا نسخة كود محلية؛ ليس تغييرًا منشورًا تلقائيًا لإضافة ChatGPT.

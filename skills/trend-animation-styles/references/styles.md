# مكتبة أساليب الأنيميشن الرائجة (كل أسلوب: متى، واللوحة، والخط، والحركة، والممنوع، ومقتطف)

اختر أسلوباً واحداً مسيطراً. انسخ قسم «DESIGN.md» إلى مشروعك ثم نفّذ بـ claude-animation-studio.

## 1. Kinetic Typography (الكلمات الحيّة)
- **متى:** اقتباسات، إعلانات نصية، كلمات أغانٍ، ريلز تحفيزية.
- **اللوحة:** خلفية واحدة مشبعة (#0E0E10 أو #1446A0 أو #F5E6C8) + نص بلون واحد عالي التباين + تمييز واحد.
- **الخط:** عربي Cairo 900 أو Changa 800؛ لاتيني Fraunces 900 أو Space Grotesk 700. الأحجام 120px+.
- **الحركة:** الكلمة المفتاحية تدخل بالقياس (0.9→1 نابض) والبقية بالشفافية؛ تتبّع حروف يتقلّص من 0.3em إلى 0؛ قطع صلب على الإيقاع.
- **الممنوع:** تفكيك الحروف العربية؛ أكثر من 5 كلمات في الظهور.
```css
.word{font-size:140px;font-weight:900;letter-spacing:-.03em;transform-origin:50% 60%}
```
```js
// scale-in بالنابض + تتبّع
el.style.transform=`scale(${lerp(.85,1,spring(seg(t,a,a+.8)))})`; el.style.letterSpacing=`${lerp(.3,0,easeOut(seg(t,a,a+.6)))}em`;
```

## 2. Glassmorphism UI Motion (واجهات زجاجية)
- **متى:** عروض منتجات رقمية، تطبيقات، لوحات تحكم.
- **اللوحة:** تدرّج خلفية عميق (#0B1B3A→#1E3A8A) + بطاقات rgba(255,255,255,.08) بحدود rgba(255,255,255,.18) + تمييز #7DD3FC.
- **الخط:** IBM Plex Sans Arabic 600 / Manrope 700.
- **الحركة:** البطاقات تدخل بـ y:40→0 وblur:12→0 بتدرّج 80ms؛ توهج خلفي يتنفس؛ مؤشر يتحرك بين العناصر بـ inOut.
- **الممنوع:** أكثر من 3 بطاقات في الإطار؛ ضبابية على النص نفسه.
```css
.card{background:rgba(255,255,255,.08);border:1px solid rgba(255,255,255,.18);backdrop-filter:blur(26px);border-radius:28px}
```

## 3. Flat Explainer (المسطّح التعليمي)
- **متى:** شرح العلوم والمنتجات والعمليات.
- **اللوحة:** فاتحة (#EAF7FF) + 4 ألوان مسطّحة بدور لكل عنصر + تمييز برتقالي #FF7A00 للمرحلة الحالية.
- **الخط:** Cairo 800/700. نص 40px+.
- **الحركة:** عنصر واحد يتحرك في كل مرحلة؛ خطوط ترسم نفسها (stroke-dashoffset)؛ أشكال تنمو من المركز؛ شريط مراحل يضيء.
- **الممنوع:** ظلال واقعية؛ أكثر من حركة رئيسية واحدة.
```js
path.style.strokeDasharray="1 1"; path.style.strokeDashoffset=String(1-easeInOut(seg(t,a,b))); // pathLength="1"
```

## 4. Paper Cut-out (الورق المقصوص)
- **متى:** قصص أطفال، تراث، محتوى دافئ.
- **اللوحة:** كريمي #F6EBD9 + ألوان ورقية مكتومة (#D96B4A، #5B8C5A، #3B6EA8) + ظل ناعم rgba(0,0,0,.18).
- **الخط:** Amiri 700 أو Lateef للعناوين؛ Tajawal 500 للنص.
- **الحركة:** طبقات بارالاكس (3 أعماق بسرعات 1، 0.6، 0.3)؛ تأرجح خفيف ±2°؛ دخول بالانزلاق مع ظل يتغيّر.
- **الممنوع:** تدرّجات ناعمة؛ حركة سريعة.
```css
.layer{filter:drop-shadow(0 8px 0 rgba(0,0,0,.18))} /* ظل ورقي صلب */
```

## 5. Isometric World (العالم الإيزومتري)
- **متى:** مدن، منتجات تقنية، خرائط عمليات.
- **اللوحة:** خلفية #111827 أو #F3F4F6 + 3 ألوان لواجهات المكعب (فاتح/متوسط/غامق لنفس الصبغة) + تمييز.
- **الخط:** Readex Pro 700.
- **الحركة:** المباني تنبثق من الأرض (scaleY من 0 بنابض) بتدرّج مكاني من المركز؛ كاميرا ثابتة أو انجراف بطيء.
- **الممنوع:** منظور حقيقي؛ أكثر من 40 عنصراً.
```js
// إحداثيات إيزومترية 2:1
const iso=(x,y,z)=>({sx:(x-y)*TILE, sy:(x+y)*TILE/2 - z});
```

## 6. Self-drawing Line Art (الخط الذي يرسم نفسه)
- **متى:** عناوين، شعارات، أيقونات تظهر، تعليم.
- **اللوحة:** خلفية فاتحة أو داكنة + خط واحد #111 أو #F4F7FF + تمييز.
- **الخط:** Changa 600.
- **الحركة:** stroke-dashoffset بالـ easeInOut بمدد متدرجة؛ ثم تعبئة تتلاشى للداخل.
- **الممنوع:** رسم كل المسارات دفعة واحدة.

## 7. Data in Motion (البيانات المتحركة)
- **متى:** إحصاءات، تقارير، أخبار.
- **اللوحة:** داكنة (#0D1B2A) + لوحة فئوية مقروءة لعمى الألوان (#3B82F6 #F59E0B #10B981 #EF4444 #A855F7) أو فاتحة.
- **الخط:** IBM Plex Sans Arabic 700 للأرقام (أرقام جدولية tabular-nums).
- **الحركة:** الأعمدة تنمو بـ easeOut بتدرّج 60ms؛ الأرقام تعدّ؛ المحور ثابت؛ الخط يرسم نفسه ثم نقطة تضيء.
- **الممنوع:** محور لا يبدأ من صفر؛ 3D؛ فطيرة متحركة.
```css
.num{font-variant-numeric:tabular-nums}
```

## 8. Glitch / Neon Cyber
- **متى:** ألعاب، تقنية، موسيقى.
- **اللوحة:** #05060A + نيون واحد (#39FF14 أو #FF2BD6 أو #00E5FF) + أبيض. لا أكثر من نيونَين.
- **الخط:** Orbitron / Share Tech Mono؛ عربي: Cairo 900 بتوهج.
- **الحركة:** قطعات صلبة قصيرة، وانزياح RGB لإطارين (clip-path + translate ±6px)، وومضة scanline؛ ثم سكون.
- **الممنوع:** وميض أكثر من 3 مرات في الثانية (إتاحة)؛ glitch مستمر.
```css
.neon{color:#fff;text-shadow:0 0 8px #00E5FF,0 0 24px #00E5FF,0 0 64px rgba(0,229,255,.6)}
```

## 9. Lo-fi / Cozy
- **متى:** موسيقى هادئة، دراسة، محتوى طويل.
- **اللوحة:** بنفسجي-أزرق مسائي (#2B2D42→#5C5470) + أصفر دافئ #F2C14E + حبيبات.
- **الخط:** Tajawal 500 / Nunito ممنوع ← استخدم Mulish أو Karla.
- **الحركة:** حلقة 4–8 ثوانٍ: مطر، بخار، ومضة مصباح، تنفّس شخصية؛ كل شيء بطيء (1–3 ث).
- **الممنوع:** قطعات؛ حركة أسرع من 0.8 ث.

## 10. Documentary Explainer (الوثائقي التوضيحي)
- **متى:** أخبار، تاريخ، سياسات.
- **اللوحة:** داكنة محايدة دافئة (#15130F) + عاجي #EFE6D8 + تمييز أحمر #C0392B أو ذهبي.
- **الخط:** Amiri 700 عناوين + IBM Plex Sans Arabic 500 نص.
- **الحركة:** تكبير Ken Burns بطيء (1.0→1.08 في 6 ث) على الصور؛ خطوط فاصلة scaleX من 0؛ أرقام تعدّ؛ خرائط تضيء.
- **الممنوع:** تأثيرات لعوبة؛ أكثر من حركة واحدة فوق الصورة.

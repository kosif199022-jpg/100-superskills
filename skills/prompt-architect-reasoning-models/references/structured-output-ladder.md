# سلّم إلزام الإخراج المهيكل (خلاصة structured-output.md المقاسة)

## ثلاث حقائق تحكم كل قرار
1. **الصلاحية ليست الصحة.** فك التشفير المقيّد يرفع صلاحية المخطط إلى 100% ولا يرفع الجواب إلى صحيح (Llama-3.1-8B: 68.7%→100% صلاحية، 31.7%→36% نجاح دلالي؛ Qwen2.5-0.5B: الدقة هبطت 19.7%→11% والمخرجات «صحيحة الشكل خاطئة المعنى» ارتفعت إلى 88.9%). قِس الصلاحية والصحة ومعدل الخطأ-الصالح كثلاثة أرقام.
2. **ضريبة الصيغة في البرومبت لا في العيّنة.** تعليمات الصيغة وحدها كلّفت 1-7 نقاط على نماذج مفتوحة في مهام التفكير (Qwen3-8B −6.6)، وصفراً أو موجباً على Haiku 4.5 وGPT-5.4-nano. السبب التاريخي: مفتاح answer قبل reason يحوّل التفكير إلى إجابة مباشرة. العلاج: الترتيب أو مرحلتان، لا حذف التعليمة.
3. **الامتثال بالتعليمات على النماذج الصغيرة قمار.** 61.5%-91.7% صلاحية تحت 8B مقابل ≈ 100% عند 30B والواجهات الحدودية. تحت ≈ 30B التعليمة مجاملة للنموذج لا ضمان للمحلّل.

## السلّم
- **الدرجة 0 (دائماً):** صِف المخطط في البرومبت حتى مع التقييد (llama.cpp/SGLang/Ollama لا تحقن المخطط). reason قبل answer. JSON أو Python لا XML عند ≤ 8B. درجة الحرارة 0 محلياً (Gemini 3 استثناء: 1.0 + responseSchema).
- **الدرجة 1: تعليمة الصيغة فقط.** تعدادات وتصنيفات ومخططات مسطّحة ≤ 12 مفتاحاً حيث فشل التحليل رخيص. توقّع 60-92% صلاحية من 0.5B إلى 8B. prefill للقوس الافتتاحي حيث يُسمح (Transformers، نقاط إكمال خام، Claude ≤ 4.5) وفقط والتفكير مغلق.
- **الدرجة 2: تعليمة + تحقق-وإصلاح.** Pydantic/Zod مع 2-3 محاولات تعيد خطأ المدقّق كرسالة؛ ميزانية رموز وشرط توقف. الحد الأدنى لأي نموذج مفتوح صغير في الإنتاج. انتقل إليها عند صلاحية < 95%.
- **الدرجة 3: مخطط API أو فك تشفير مقيّد.** Anthropic: اطلب أولاً ← محاولات ← أداة enum أو structured outputs (`output_config.format` بـ json_schema؛ غير مدعوم: المخططات العودية، minimum/maximum، minLength/maxLength، additionalProperties غير false ← يفرضها مدقّقك). OpenAI: `text.format` + strict. Gemini: responseSchema. مفتوح: Ollama format، llama.cpp grammar، vLLM/SGLang بـ XGrammar/llguidance (كلفة ≈ 0؛ Outlines يبطّئ). عند 8B الدقة الدلالية تتحسن قليلاً أيضاً. ≤ 1.5B: ضريبة القيد قد تنصّف الدقة؛ ابقَ على 2 أو أضف مدقّق مجال وفشل مغلق.
- **الدرجة 4: فكّر ثم قيّد.** للرياضيات والمنطق والاستخراج متعدد الخطوات: استدعاءان (حر ثم إعادة تنسيق: +6.8 نقطة في المتوسط)، أو وضع التفكير ثم القيد بعده (+9.2 متوسطاً لكن أسوأ في 11/72؛ قِس)، أو نحو واحد بمنطقة تفكير حرة قبل الجواب المقيّد (CRANE حتى +10). vLLM يطبّق القيد بعد كتلة التفكير افتراضياً؛ Ollama يحجب بعد رمز نهاية التفكير (لذلك think=false يعطّل format على gemma4 في 0.20.x). لا prefill للقوس هنا.

## رافعات البرومبت وقيمتها
| الرافعة | القيمة |
|---|---|
| المخطط في النص بالمفاتيح والأنواع | مطلوب في كل درجة |
| أسماء المفاتيح | قناة تعليمات تحت التقييد؛ تغيير الكلمة وحده يغيّر الدقة |
| ترتيب المفاتيح | reason قبل answer |
| مثال واحد للمخرج | يرفع الامتثال على الصغيرة (76.5% مقابل 67%) |
| «أجب بـ JSON فقط» | يمنع المقدمة؛ يكلّف 1-7 نقاط تفكير على المفتوحة؛ أبقِه وانقل التفكير |
| إزالة أسوار الكود في المحلّل | مطلوبة لـ Gemma 4 على Ollama |

## التقييم الذي يحتاجه قرار الشكل
على 100 مدخل حقيقي على الأقل: صلاحية المخطط، ودقة الجواب، والدقة التنفيذية حيث يُنفَّذ المخرج، ومعدل الخطأ-الصالح. فشل التحليل يُسجَّل منفصلاً عن الجواب الخاطئ. التحقق من المجال بعد مخطط، والنظام يفشل مغلقاً على أيهما.
